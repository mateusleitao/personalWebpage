# Product

## Purpose

The homepage gives visitors a clear introduction to Lange and a fast route to
his public developer profiles. It should communicate identity and professional
focus without requiring navigation or interaction beyond following a link.

## Audience

- Recruiters and potential collaborators
- Developers discovering Lange's work
- Visitors using mobile, keyboard, zoom, or assistive technology

## Current content contract

- The page title identifies Lange as a web developer.
- The visible introduction contains one main heading: “Hi, I'm Lange”.
- The page describes Lange as a web developer.
- Exactly three public profile links are present: GitHub, LinkedIn, and Dev.to.
- The portrait is meaningful identity content and has descriptive alternative
  text.

## Current non-goals

- Multiple routes or client-side routing
- Contact forms, authentication, analytics, or a content management system
- A project catalogue or blog rendered inside this application
- TypeScript migration before the application gains structured data or logic

When scope grows, update this document and add acceptance criteria before
implementation.
